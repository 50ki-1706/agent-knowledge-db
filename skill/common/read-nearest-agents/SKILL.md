## 説明

編集箇所に一番近い `AGENTS.md` を先に読み、その指示とチャットの優先順位に従って作業する手順。

## 本文

1. 変更するファイルのディレクトリから親へ辿り、最初に見つかった `AGENTS.md` を読む。複数あっても、より近いファイルを優先する。
2. そこに書かれたビルド、テスト、lint、コードスタイルを、今回の変更に関係するものから実行する。
3. チャットの指示とファイルの指示が衝突したら、チャットに従う。
4. `AGENTS.md` が無いときは、`package.json` の scripts、CI、`pyproject.toml`、`devenv.nix` から既存のコマンドを探す。新しいツールチェーンを足して検査を作らない。
5. コマンドを実行する前に、検査が通ったと報告しない。
