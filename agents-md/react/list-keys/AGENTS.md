## 説明

リスト描画の `key` に、データの安定した ID を使うための指示。

## 本文

配列をリストにするとき、各要素の `key` にはそのデータの安定した ID を使う。`key={person.id}` のように、並べ替えや挿入の後も同じ項目が同じ `key` になる値にする。

`key` は React へのヒントであり、コンポーネントの props には渡らない。子が ID を必要とするときは `key` とは別に prop で渡す。

描画のたびに `key={Math.random()}` のようにキーを生成しない。キーが一致しなくなり、リスト項目の state と入力が捨てられる。

インデックスを `key` にしてよいのは、並びが変わらないリストに限る。挿入、削除、並べ替え、フィルタがあるリストでは、インデックスは項目の同一性を表さない。ID が無い内側のリストで、同じ親の中では値が重複しないと分かっているときは、その値自体を `key` にできる。重複するならデータに ID を足す。
