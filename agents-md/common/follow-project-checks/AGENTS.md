## 説明

作業の完了前に、そのリポジトリがすでに定義している確認コマンドを実行するための指示。

## 本文

編集するファイルから親ディレクトリを辿り、最も近い `AGENTS.md` を読む。そこにある install、dev、test、lint を、今回の変更に関係するものから実行する。モノレポでは、ルートのファイルより編集箇所に近いファイルを優先する。チャットの指示とファイルの指示が衝突したときは、チャットを優先する。

確認コマンドの記載が無いときは、次の既存の定義を探し、そこに書かれているコマンドだけを使う。

- `package.json` の `scripts`
- CI ワークフロー
- `pyproject.toml` と `uv.lock` があるプロジェクトの `uv run`
- `devenv.nix` の tasks、scripts、processes

定義が無いコマンドを、完了条件として新しく導入しない。テストランナー、リンター、パッケージマネージャを、既存の設定を見ずに追加しない。

コマンドを実行する前に成功したと書かない。失敗したら、変更に起因するものを直す。環境要因で実行できないときは、実行したコマンドと止まった理由を残す。
